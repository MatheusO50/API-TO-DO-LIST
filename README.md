## 🧰 Tecnologias Utilizadas
- Linguagem: C#
- Framework: ASP.NET
- Banco de Dados: PostgreSQL
- Empacotagem: Docker

## ⚙️ Pré-requisitos
- .NET 10 (ou superior)
- Git
- PostgreSQL

## 🚀 Como executar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/MatheusO50/API-TO-DO-LIST.git
```

2. Entre na pasta do projeto:
```bash
cd API-TO-DO-LIST
```

3. Inicie o Projeto
```bash
dotnet run
```
